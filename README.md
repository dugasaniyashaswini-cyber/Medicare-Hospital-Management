MediCare – Hospital Appointment Management System

1. Project Overview

MediCare is a web-based Hospital Appointment Management System developed using HTML, CSS and JavaScript. It provides a simple platform for patients to register, log in, search for doctors and book hospital appointments.

The application uses a professional red-and-white theme to provide a clean and user-friendly interface.

2. Technologies Used

- HTML5 – Website structure
- CSS3 – Styling and responsive design
- JavaScript – Application functionality
- LocalStorage – Storing user and appointment details in the browser

3. Main Features

Patient Module

- Patient registration
- Patient login
- Search doctors
- View doctor specializations
- Book appointments
- View appointment details
- Cancel appointments

Doctor Module

- View appointment requests (doctor login requires further implementation)
- Approve appointments (doctor login requires further implementation)

Admin Module

- Admin login
- View total patients
- View total doctors
- View total appointments
- View pending appointments
- Cancel appointments

4. Doctor Specializations

6. Installation and Execution

1. Install Visual Studio Code.
2. Create a folder named MediCare.
3. Create a file named index.html.
4. Copy the complete source code into the file.
5. Save the file.
6. Open the file in Google Chrome or use VS Code Live Server.

8. Storage

The application uses browser LocalStorage to save patient registration details and appointment information.

Data remains available in the same browser unless its site data is cleared.

MediCare provides a simple and convenient way to manage hospital appointments. It helps patients find doctors and schedule appointments through an easy-to-use interface. The project demonstrates the practical application of HTML, CSS and JavaScript in developing a healthcare management system.
